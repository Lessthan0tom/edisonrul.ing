# X-Saber Axel

## Edisonformat.net (Revised, Post-UTW Rulings)

Source: [https://edisonformat.net/card?name=X-Saber%20Axel](https://edisonformat.net/card?name=X-Saber%20Axel)

### Edison-Accurate PSCT

> ① If an "Saber" monster is destroyed by battle and sent to the GY: Draw 1 card.
> (This card must remain face-up on the field to activate and to resolve this effect.)

### Card Rulings

*   If this card is destroyed by battle, this effect will not activate.

*   This effect will activate if your opponent's "Saber" monster is destroyed by battle and sent to the GY.

*   If this card is not face-up when this effect would resolve (e.g. if "Raigeki Break" is chained), you do not draw a card.

*   If two "Saber" monsters destroy eachother by battle, this effect will trigger twice within the same chain on different chain links.
